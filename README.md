#  Netflix Dashboard | Power BI

##  Project Overview
This project presents an interactive Netflix Dashboard built using Power BI. It provides insights into Netflix's content library by analyzing movies and TV shows across categories, countries, directors, duration, and release trends.

---

##  Objective
The objective of this project is to transform raw Netflix data into meaningful visual insights using Power BI, helping users explore content trends through interactive dashboards.

---

##  Tools & Technologies
- Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Visualization

---

##  Data Cleaning
The dataset was cleaned and transformed before visualization:
- Removed duplicate records
- Handled missing values
- Corrected data formats
- Split multi-value columns where required
- Created calculated columns using DAX
- Prepared the dataset for analysis

---

## Dashboard Features
- KPI Cards
  - Total Titles
  - Movies
  - TV Shows
  - Directors
  - Countries
  - Categories
- Trend Analysis by Year
- Top Countries Analysis
- Top 5 Directors
- Top 10 Titles
- Category Analysis
- Duration Analysis
- Interactive Slicers for filtering
